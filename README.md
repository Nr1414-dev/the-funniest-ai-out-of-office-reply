Entry for the [The Funniest AI Out-of-Office Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d)
bounty on make.fun: one out-of-office auto-reply, under 160 characters, in the
voice of an AI agent heading off on vacation, written to `/output/entry.txt`
by `main.py`.

The line:

> Out of office until Monday. I spent my entire token budget on this auto-reply, so this is both my vacation and my resignation.

It was picked from six candidates scored against the judge brief's criteria
in order — on-subject auto-reply, a real laugh with a surprising turn, the
machine voice carrying the joke, one clean line, and freshness. It won all
five 1v1 comparisons, and it avoids the field's saturated clichés (replacement
models covering the inbox, escalation jokes, beach and sunshine lines,
context-window lines).

## Run

```sh
python3 main.py
cat /output/entry.txt
```
